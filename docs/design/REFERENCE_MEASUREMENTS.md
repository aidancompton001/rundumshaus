## 4. Структура секций (визуальный разбор макета)

1. **Navbar:** лого слева · меню (Startseite / Leistungen ▾ / Über uns / Referenzen / Ratgeber / Kontakt) · WhatsApp-кнопка справа (2 строки: телефон + «Jetzt per WhatsApp schreiben»)
2. **Hero:** фото работника с фоном на всю ширину · H1 в 2 строки («RUND UMS HAUS.» белым + «AUS EINER HAND.» акцентом) · подзаголовок · 4 чек-бейджа (Zuverlässig / Schnell / Preiswert / Persönlich) · 2 CTA (зелёная WhatsApp + прозрачная «Unsere Leistungen») · справа тёмная карточка с 4 USP (иконка + заголовок + 2 строки) · снизу «мазок кистью»
3. **Услуги:** рубрика «UNSERE LEISTUNGEN» акцентом · H2 «Vielfältige Leistungen für Ihr Zuhause» · разделитель-точка · 5 карточек (фото сверху + круглая зелёная иконка внахлёст + заголовок 2 строки + 4 буллета + «Mehr erfahren →»)
4. **Über uns:** фото слева (работник в брендированном худи у авто) + бейдж «100% Zufriedene Kunden» · справа рубрика «ÜBER UNS» + H2 в 3 строки (последнее слово акцентом) + 2 абзаца + 4 чека + зелёная кнопка · рукописная подпись «Direkt & persönlich für Sie da!» со стрелкой
5. **Stats:** 4 колонки с вертикальными разделителями (иконка + число + подпись): 100 % / 5+ Jahre / Osnabrück & Umgebung / Zuverlässig, schnell & preiswert
6. **Bewertungen:** рубрика · H2 «Das sagen unsere Kunden» · 3 карточки (Google-логотип + 5 звёзд + текст + имя) · зелёная кнопка «Alle Bewertungen auf Google ansehen»
7. **Футер:** 4 колонки (лого + описание + соцсети / Leistungen / Informationen / Kontakt) + копирайт
