ПРОИЗВОДНЫЕ (выбраны нами, в макете не измерялись — это честная пометка):

  --accent-ink:    #4A6B16   /* ТОЛЬКО для акцентного ТЕКСТА на светлом фоне, см. блок контраста */
  --accent-hover:  #4A6B16   /* hover-состояние заливок (~18% темнее --accent) */
  --dark-soft:     #1A2230   /* карточки/блоки на тёмном фоне */
  --ink:           #14181F   /* основной текст */
  --ink-muted:     #5A6472   /* вторичный текст */

КОНТРАСТ — посчитанные значения, не оценка (WCAG AA):

  белый на --accent      = 4.68:1  → ПРОХОДИТ. Так делаются все зелёные кнопки (текст белый, вес 600+)
  --accent на --paper    = 4.41:1  → НЕ ПРОХОДИТ для мелкого текста
  --accent-ink на --paper = 5.81:1 → ПРОХОДИТ. Поэтому рубрики CAPS («UNSERE LEISTUNGEN»),
                                     ссылки «Mehr erfahren →» и любой мелкий акцентный текст
                                     на светлом фоне красятся в --accent-ink, а НЕ в --accent
  --accent на --dark     = 3.85:1  → только иконки/графика (порог 3:1), НЕ мелкий текст
  белый на --dark        = 18.04:1 → ПРОХОДИТ везде

Визуально --accent и --accent-ink почти неразличимы, поэтому это НЕ отступление от макета.

СТЕК ПРОТОТИПА
═══════════════════════════════════════════════════════════

- Vanilla HTML5 + CSS3 + минимум JS (dropdown, аккордеон FAQ, бургер, scroll-reveal)
- Запускается локально: `python -m http.server 8000`
- Никаких сборщиков, никакой экзотики. Код будет переписан в Next.js 16 + Tailwind 4 —
  поэтому пиши так, чтобы классы и структура легко мапились в Tailwind-утилиты.
- Все цвета/размеры — через CSS-переменные в `tokens.css`, ни одного хардкод-хекса в разметке.

Анимации — уровень СДЕРЖАННЫЙ (это сайт мастера, не агентства):
- Плавные scroll-reveal секций (fade + 8-12px подъём)
- Hover карточек: тень + сдвиг стрелки «Mehr erfahren», БЕЗ scale-трансформа (не должно дёргать layout)
- Счётчик в stats-полосе (0 → значение) при появлении
- `prefers-reduced-motion: reduce` — все анимации выключены, контент сразу виден
- ⛔ НЕ использовать: параллакс, WebGL, тяжёлые библиотеки, magnetic cursor, marquee
