Anleitung: Website bearbeiten

So bearbeiten Sie Texte, Bilder und Inhalte auf Ihrer Website.

Ihre Website hat einen visuellen Editor. Einfach Text eingeben, auf Save klicken — fertig. Die Website aktualisiert sich automatisch in 1–2 Minuten. Sie brauchen keine Programmierkenntnisse.
1

Anmelden

  1. Öffnen Sie app.pagescms.org in Ihrem Browser
  2. Klicken Sie auf «Sign in with GitHub»
  3. Melden Sie sich mit Ihren GitHub-Zugangsdaten an
  4. Wählen Sie das Projekt rundumshaus aus
Links im Menü sehen Sie alle Bereiche: Firmendaten, Startseite, Leistungen usw.
2

Firmendaten ändern

Firmenname, Adresse, Telefon, E-Mail.

  1. Klicken Sie links auf Firmendaten
  2. Ändern Sie die gewünschten Felder
  3. Klicken Sie oben rechts auf Save
Firmendaten bearbeiten
3

Startseite bearbeiten

Überschrift, Unterüberschrift und «Über uns»-Text.

  1. Klicken Sie links auf Startseite
  2. Hero-Bereich: Überschrift und Unterüberschrift ändern
  3. Über uns: Text und Überschrift ändern
  4. Klicken Sie auf Save
Startseite — Hero & Über uns
4

Hauptleistungen bearbeiten

Texte der 5 Hauptleistungen (Hausmeisterservice, Gartenpflege usw.).

  1. Klicken Sie links auf Hauptleistungen
  2. Wählen Sie eine Leistung (z.B. Item #1)
  3. Ändern Sie Titel, Kurzbeschreibung oder Detailbeschreibung
  4. Klicken Sie auf Save
Hauptleistungen — Texte bearbeiten
Hinweis: Die 5 Hauptleistungen bitte nicht löschen — nur die Texte ändern.
5

Weitere Dienstleistungen

Neue Dienstleistungen hinzufügen oder bestehende entfernen.

  1. Klicken Sie links auf Weitere Dienstleistungen
  2. Scrollen Sie nach unten → klicken Sie auf + Add an item
  3. Geben Sie den Namen der neuen Dienstleistung ein
  4. Zum Löschen: Papierkorb-Symbol rechts neben dem Eintrag
  5. Klicken Sie auf Save
Dienstleistungen — Liste
Hinzufügen — «+ Add an item»
6

Referenzen hinzufügen

Projekte mit Vorher/Nachher-Bildern zeigen.

  1. Klicken Sie links auf Referenzen
  2. Bei Projekte auf + Add an item klicken
  3. Felder ausfüllen: ID (z.B. garten-01), Titel, Beschreibung, Datum (JJJJ-MM)
  4. Vorher-Bild und Nachher-Bild hochladen
  5. Klicken Sie auf Save
Referenz — Titel, Beschreibung, ID
Referenz — Datum & Vorher/Nachher-Bilder
7

Bilder hochladen

Im Bereich Media verwalten Sie alle Bilder.

  1. Klicken Sie links auf Media
  2. Ordner: branding, hero, kontakt, referenzen, services
  3. Klicken Sie oben rechts auf Upload
Media — Bilder verwalten
Tipp: JPG oder PNG, maximal 2 MB pro Bild.
8

Kontaktformular-Texte

Überschrift, Einleitung, Button-Text, Erfolgs-/Fehlermeldung.

  1. Klicken Sie links auf Kontaktformular
  2. Ändern Sie die gewünschten Texte
  3. Klicken Sie auf Save
Kontaktformular — Texte

Gut zu wissen

Sie können nichts kaputt machen. Wenn etwas schiefgeht, bleibt die alte Version online.

Nicht ändern: Design, Layout und Navigation — dafür sind wir da.
