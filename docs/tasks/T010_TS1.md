# ТС1 — T010: тексты клиента в редизайн без потерь

**Ответственный:** #1 Product Architect
**Размер:** L
**Скиллы:** `hrc`, `hans-landa`, `verification-before-completion`, `systematic-debugging` (при расхождениях)

## Цель

Вернуть в мокап редизайна (`docs/design/v1-desktop/`) тексты клиента из `site/src/data/*.json` и доказать машинно, что ни один не потерян и ни один не выдуман.

## Разведка — что уже установлено (машинно)

| Факт | Значение | Как получено |
|---|---|---|
| Точек `data-cms` в мокапе, уникальных | 136 | `grep -oh 'data-cms="[^"]*"' docs/design/v1-desktop/*.html \| sort -u \| wc -l` |
| Вхождений (с повторами на разных страницах) | 141 | тот же grep без `sort -u` |
| Строковых полей в источниках | homepage 45, site 23, services 46, referenzen 40, ratgeber 89, weitere-leistungen 12, service-faq 26, reviews 53 | обход JSON |

**Ловушка №1, уже подтверждённая.** Индексы услуг не совпадают:

| Индекс | В мокапе | В `services.json` |
|---|---|---|
| `services[0]` | Gartenpflege | hausmeisterservice |
| `services[4]` | Garten- & Landschaftsbau | garten-landschaftsbau |

Маппинг вести **по `id` услуги**, никогда по индексу. Слепая подстановка по индексу перепутает 4 услуги из 5.

**Ловушка №2, уже подтверждённая.** Имена ключей мокапа не равны именам в JSON: мокап `homepage.hero.title` ↔ JSON `hero.heading`. Автоматическое сопоставление по имени невозможно, маппинг объявляется явным файлом.

**Ловушка №3, уже подтверждённая.** Тексты в мокапе сейчас сочинены под вёрстку. Пример `services[0].description`: «Ein gepflegter Garten braucht regelmäßige Aufmerksamkeit…» — такого текста у клиента нет вообще.

## Скоуп

**Включено:**
- `docs/design/v1-desktop/*.html` — подстановка текстов во все 136 точек
- `docs/design/v1-desktop/css/style.css` — правки вёрстки, если текст клиента не помещается
- новый инструмент `verify/check_client_texts.py` + мутационный самотест `verify/selftest_client_texts.py`
- явный маппинг `docs/design/MAPPING_cms_to_data.json`
- перезалив превью на сервер CEO

**НЕ включено:**
- `site/` — источник, не приёмник. Ни одной правки
- перенос мокапа в Next.js (это фазы Ф4–Ф8 T008, отдельная задача)
- изменение самих текстов клиента в любую сторону

## Решение по спорному месту: буллеты

В `index.html` 20 буллетов, сочинённых при вёрстке (`Rasenmähen`, `Pflasterarbeiten`, …). У клиента их нет как отдельного поля — есть `description` и `detailDescription` сплошным текстом.

Решение: **буллеты удаляются, на их место идёт `description` клиента целиком.** Основание — прямая просьба клиента «unsere Texte behalten». Оставить сочинённые буллеты рядом с текстом клиента значит оставить на сайте текст, которого клиент не писал, ровно после просьбы этого не делать.

Последствие для вёрстки: `description` у Hausmeisterservice — 389 знаков против 4 буллетов по 12–22 знака. Карточки станут заметно выше и разной высоты. Вёрстка правится под текст (grid с выравниванием), текст под вёрстку — нет.

## Критерии приёмки

- [ ] Маппинг покрывает все 136 точек: каждая либо привязана к полю источника, либо в списке `not_from_data` с причиной

## Решение по буллетам — переигрывается

ТС1 предлагала удалить буллеты и вставить `description`. Landa нашёл третий выход, и он лучше: **у клиента есть собственные списки** — `templates/<id>.json` → `leistungen.items`, всего 101 позиция (gartenpflege 26, hausmeisterservice 22, entruempelung 22, dacharbeiten 20, garten-landschaftsbau 11).

- `index.html` — буллеты заполняются первыми 4 позициями клиентского списка по `id`
- `leistungen.html` — `subservices` первыми 6 позициями, `description` = `detailDescription` дословно с абзацами

Обе просьбы клиента выполняются одновременно, выбор «текст против дизайна» не нужен.

## Матрица мутаций самотеста (обязательна, 8 случаев)

a) удалить слово из середины description; b) обрезать хвост до многоточия; c) переставить слова в title; d) заменить `&` на `&amp;` с одной стороны; e) склеить два абзаца в один; f) добавить `-webkit-line-clamp:3`; g) переставить услуги местами; h) перенести точку из `mapped` в `not_from_data`. Каждая обязана дать красный.
