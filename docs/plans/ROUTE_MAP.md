## Что это значит числом

- Маршрутов всего: **16** плюс страница 404
- Покрыто макетом: **8** маршрутов → 596 страниц
- **Без макета: 7 содержательных маршрутов → 16 страниц, из них 19 адресов в карте сайта**
- Два маршрута (`/services/`, `/weitere-leistungen/`) — технические редиректы, дизайн им не нужен

## Почему `/osnabrueck/` важнее остальных

Это единственная страница сайта с приоритетом **0.95** в карте сайта — выше только главная (1.0). Она собирает поисковый спрос по главному городу клиента. Оставить её в старом дизайне значит: посетитель из Google приходит на страницу, которая выглядит не как остальной сайт.

## РЕШЕНИЕ CEO (2026-08-13): вариант А для всех семи

Весь сайт приводится к одному дизайну. Ни одна страница не остаётся в старом
оформлении. Ниже — варианты, из которых выбран А, оставлены для истории.

### Что это добавляет к работе

| Маршрут | Из чего собирается | Оценка |
|---|---|---|
| `/osnabrueck/` | блоки городской страницы + герой главной | средне |
| `/einsatzgebiet/` | список городов + блок «Einsatzgebiet» с главной | легко |
| `/ratgeber/` | карточки статей — сетка как у услуг | легко |
| `/ratgeber/[slug]/` | типографика статьи: заголовки, абзацы, списки | средне |
| `/leistungen/objektpflege/` | блок страницы услуг | легко |
| `/leistungen/rasen-neuanlage/` | блок страницы услуг | легко |
| 404 | шапка, подвал, один экран | легко |

Итого 16 страниц сверх 596 уже покрытых. Приёмка та же: после каждой —
`БИНАРНО: 1`.

## Варианты, из которых выбирали

**А. Отрисовать по аналогии.** Взять компоненты из перенесённых страниц: `/osnabrueck/` и `/einsatzgebiet/` собираются из тех же блоков, что и городская страница; `/ratgeber/` — из карточек, которые уже есть в макете; `objektpflege` и `rasen-neuanlage` — из блоков страницы услуг; 404 — из шапки, подвала и одного экрана.
Оценка: примерно треть объёма переноса сверху. Результат — весь сайт в одном дизайне.

**Б. Оставить в старом дизайне осознанно.** Сайт живёт в двух дизайнах. Дёшево, но посетитель это видит, и на `/osnabrueck/` это видит поисковый трафик.

**В. Отложить.** Перенести восемь маршрутов, остальные — следующей задачей. Промежуточное состояние то же, что и в варианте Б, но с обещанием закрыть.

Рекомендую **А** для `/osnabrueck/`, `/einsatzgebiet/` и 404 — это четыре страницы и главный трафик, — а `ratgeber` и две посадочные решать вместе с вопросом о судьбе раздела статей.
