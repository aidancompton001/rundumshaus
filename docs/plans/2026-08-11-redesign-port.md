**Цель:** поставить дизайн из `docs/design/v1-desktop/` на живой сайт так, чтобы ни один из 617 адресов, 511 записей карты сайта и 100 редиректов не пропал, а клиент продолжил править тексты через свою админку.

**Стек:** Next.js 16 SSG (`output: export`), Tailwind 4, Sveltia CMS на GitHub-бэкенде, деплой GitHub Pages.

Слой данных не меняется, значит редактирование клиентом не ломается.

## Бинарный приёмочный критерий

Инструмент `verify/check_migration_parity.py` снимает слепок сборки (адрес → title, description, canonical, robots, h1, meta refresh, типы JSON-LD) и сравнивает два слепка. Дизайн-специфичное не сравнивается — оно меняется по замыслу; сравнивается смысл страницы.

Базовый слепок ДО переноса уже снят: `verify/snapshots/before-redesign.json` — 617 страниц, 511 адресов, 100 редиректов.

Фальсифицируемость доказана: слепок сам с собой даёт `PARITY_OK / БИНАРНО: 1`; после удаления трёх городских страниц, подмены одного canonical и урезания карты сайта — `PARITY_LOST:3 / БИНАРНО: 0`.

**Перенос принимается только при `БИНАРНО: 1`.** Любое другое значение — работа не закончена.
