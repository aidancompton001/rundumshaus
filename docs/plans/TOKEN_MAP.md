## Два места, где нельзя действовать механически

**Золотой.** `gold` и `gold-light` (25 употреблений) в палитре редизайна отсутствуют вовсе. Он красит звёзды рейтинга и мелкие акценты. Варианты: перенести как есть отдельным токеном `--color-star`, либо заменить акцентным зелёным. Решение принимается до начала Задачи 2, иначе 25 мест останутся без цвета.

**Наведение на кнопку.** У сайта `copper-light` **светлее** основного, у макета `accent-hover` **темнее**. Механическая замена перевернёт поведение кнопок: сейчас при наведении они светлеют, станут темнеть. Это заметное изменение, его надо принять осознанно.

## Порядок замены — иначе сайт обесцветится посреди работы

1. Добавить новые токены в `globals.css`, **не удаляя старые**.
2. В блоке `@theme inline` завести соответствие: `--color-copper: var(--color-accent)` и так далее. Утилиты `bg-copper` продолжают работать, но берут новый цвет. Сайт перекрашивается целиком, ни один компонент не трогается.
3. Прогнать: сборка, тесты, приёмка `БИНАРНО: 1`, снимки экранов до и после.
4. Только после этого — при желании — переименовать утилиты в 46 компонентах отдельной задачей. Это косметика, к переносу дизайна она не обязательна.

Пункт 2 — суть приёма: **956 употреблений в коде не трогаются вообще**, меняется только то, на что указывает имя.
